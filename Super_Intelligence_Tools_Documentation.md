# Super Intelligence Tools Documentation

This project uses Super Intelligence (SI) tools to assist with programming and media creation.

| Workflow | Tools | Use |
| --- | --- | --- |
| Programming assistance | Google Antigravity, GitHub Copilot | Help with writing, understanding, and debugging code. |
| Audio generation | ElevenLabs | Generate audio for the project. |
| Video generation | Gemini | Generate video content for the project. |

Super Intelligence-generated code and media are reviewed by the project team before use. Scientific information is checked against the project's cited sources.
